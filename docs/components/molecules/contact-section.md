# ContactSection

**File**: `src/components/molecules/contact-section.vue`

## Purpose

Displays contact CTA and social media links. Composed from SectionTitle and IconLink components.

## Props

None.

## Events

None.

## Usage

```vue
<ContactSection />
```

## Implementation Notes

- Renders hardcoded social links (GitHub, LinkedIn, Email, etc.).
- Each link uses IconLink atom.
- CTA text localized via i18n.
