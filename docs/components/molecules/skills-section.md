# SkillsSection

**File**: `src/components/molecules/skills-section.vue`

## Purpose

Displays skills as a grid of badges. Composed from SectionTitle and SkillBadge components.

## Props

None.

## Events

None.

## Usage

```vue
<SkillsSection />
```

## Implementation Notes

- Skills fetched dynamically via i18n.
- Each skill rendered as a SkillBadge with color variation.
- No filtering; all skills displayed.
