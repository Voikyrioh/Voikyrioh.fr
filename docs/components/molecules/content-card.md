# ContentCard

**File**: `src/components/molecules/content-card.vue`

## Purpose

Generic wrapper for card-based content. Provides consistent styling and layout.

## Props

None.

## Slots

- **default** — Card content.

## Usage

```vue
<ContentCard>
  <p>Card content goes here</p>
</ContentCard>
```

## Implementation Notes

- Uses Tailwind shadow and border radius for card appearance.
- Responsive padding.
