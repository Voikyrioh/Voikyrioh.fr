# Documentation Index

## Overview

Frontend documentation for **voikyrioh.fr**, a Vue 3 portfolio website showcasing projects, experience, and skills.

## Structure

| Section | Purpose |
|---|---|
| [ARCHITECTURE.md](../ARCHITECTURE.md) | System design: component hierarchy, pages, routing, tech stack. |
| [adr/](adr/INDEX.md) | Architectural Decision Records (frameworks, styling, testing). |
| [business-rules/](business-rules/INDEX.md) | Business logic rules (project status, visibility, i18n). |
| [bugs/](bugs/INDEX.md) | Known bugs and fixes (reference via FIX:ULID tickets). |
| [components/](components/INDEX.md) | UI component inventory (atoms, molecules, pages). |

## Quick Links

- **Start development**: `npm run dev` → http://localhost:5173
- **Build**: `npm run build`
- **Test**: `npm run test`
- **Coverage**: `npm run coverage`
- **Deploy**: See `infra-impact.md` in orga-global hub.

## Design System

Uses Tailwind CSS 4 utility classes. Custom tokens in `src/style.css`. No external component library.
